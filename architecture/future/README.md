# Future Architecture Documents

This directory contains architectural design documents for planned features
that are not yet implemented. These documents capture design intent, tradeoff
analysis, and architectural direction for future work.

Documents here are forward-looking and may evolve as implementation begins.
They are linked from `roadmap.md` where applicable.

When a feature moves from planned to in-progress, the relevant architecture
document should be promoted to the parent `architecture/` directory and linked
from the root `architecture.md`.
