# Roadmap

This file is the canonical implementation roadmap for the project.

Use it to decide whether an idea is ready for active work:

1. Broad or scope-changing ideas must sharpen this roadmap before
   implementation starts.
2. Bounded bug fixes, refactors, reliability work, and test stabilization may
   start directly from a work package when they fit an existing roadmap row or
   approved maintenance scope.
3. A roadmap row may be treated as complete only when no active package is
   still fixing the same declared exit criterion.
