# Architecture Steering Pointer

This file exists so LLM agents know where architecture truth lives.

The canonical architecture entrypoint is `../../architecture.md`.

Use that root document for:

1. Component ownership.
2. Runtime and data boundaries.
3. Shared contract vocabularies.
4. Current owner maps.
5. Supporting architecture records.

When architecture changes, update `../../architecture.md` and any affected
supporting files in the same package.
