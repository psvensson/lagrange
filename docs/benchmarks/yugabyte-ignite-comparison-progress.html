Distributed SQL Replication and Tablet RPC Comparison

YugabyteDB 2024.2 distributes SQL over DocDB tablet storage using per-tablet Raft (RF=3):

  • App service vs stored procedure: yugabytedb-ysql-rf3 incurs repeated app-to-TServer SQL round-trips. Stored procedures (yugabytedb-stored-proc) eliminate external hops.
  • Cross-tablet RPC overhead: Remote tablet RPCs evaluate multi-hop shape throughput.
  • Contended OLTP baseline: Tablet Raft replication evaluates cross-tablet 2PC commit latency.

Colocated Compute Comparison (Apache Ignite 3 vs Citus vs Lagrange)

Evaluating colocated compute grid execution (JobTarget.colocated) in Apache Ignite 3 against Citus distributed functions and Lagrange native WASI actor state:

  • Single-locality control: On local-only decisions, evaluating Apache Ignite 3 (ignite3-colocated-compute), Citus distributed functions, and Lagrange.
  • Cross-partition compute dispatch: In cross-partition shapes, Ignite 3 dispatches compute jobs via binary protocol across cluster nodes.
  • Per-shape crossover: Multi-hop shapes evaluate the trade-off between serial RPC hops, coprocessor pushdown, and in-process execution.
  • Lagrange native advantage: Lagrange native actor state maintains colocated compute; comparative performance claims await admitted GCP/lab measurements.
