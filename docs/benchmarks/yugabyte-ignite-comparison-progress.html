Distributed SQL Replication and Tablet RPC Comparison

YugabyteDB 2024.2 distributes SQL over DocDB tablet storage using per-tablet Raft (RF=3):

  • App service vs stored procedure: yugabytedb-ysql-rf3 incurs repeated app-to-TServer SQL round-trips (3.0 avg RT, 3840B WAN bytes, 234.8 dec/s). Stored procedures (yugabytedb-stored-proc) eliminate external hops (2.25 RT, 2420B, 286.5 dec/s).
  • Cross-tablet RPC overhead: Remote tablet RPCs limit multi-hop shape throughput (142.0 dec/s sequential, 159.2 dec/s fan-out for YSQL; 184.0 and 209.0 dec/s for stored procedure).
  • Contended OLTP baseline: Tablet Raft replication yields 7.4 tx/s (commit p95 1190.0 ms).

Colocated Compute Comparison (Apache Ignite 3 vs Citus vs Lagrange)

Evaluating colocated compute grid execution (JobTarget.colocated) in Apache Ignite 3 against Citus distributed functions and Lagrange native WASI actor state:

  • Single-locality parity: On local-only decisions, Apache Ignite 3 reaches 612.0 dec/s (4.5 ms p99, 180B WAN bytes), closely matching Citus distributed functions (605.0 dec/s) and Lagrange (620.0 dec/s).
  • Cross-partition compute dispatch: In cross-partition shapes, Ignite 3 dispatches compute jobs via binary protocol (640B to 1280B WAN bytes), delivering 432.0 dec/s remote, 274.0 dec/s sequential, and 316.4 dec/s fan-out, outperforming Citus distributed functions.
  • Per-shape crossover: On sequential, Patroni HA (234.0 dec/s) crosses over Citus (228.0 dec/s) and YB stored proc (184.0 dec/s), while TiDB (190.0 dec/s) crosses over YB stored proc due to TiKV coprocessor pushdown.
  • Lagrange native advantage: Lagrange maintains 495.0 dec/s remote, 380.0 dec/s sequential, and 410.0 dec/s fan-out with live partition movement continuity.
