Provenance Qualification Across Historical Milestones

Historical progression explicitly distinguishes physical cluster measurements from modeled topological projections:

  • observed-docker-cluster (live-cluster-wire): Scenario A runs in a 5-node Docker cluster over live socket connections.
  • modeled-topology-oracle (local-oracle-plus-network-model / local-js-oracle): Scenario B distributed risk decision and Scenario C streaming feature evaluation are evaluated using simulated 3-island WAN topology models.
