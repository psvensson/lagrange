1. 6-VM Cloud Cluster Sizing & Provisioning Scripts (5 Cluster Nodes + 1 Client VM)

The runner deploys the 7 measured configurations across Lagrange 0.4.0, TiDB/TiKV v8.5.8, and PostgreSQL 17 using public container images and native wire protocols (mysql2/promise, pg.Pool, and Lagrange Admin WebSocket/HTTP), writing immutable raw observations to data/tidb-comparison/raw-observations.ndjson and deriving data/tidb-comparison/admitted-lab-measurements.json (while marking unmeasured comparators [not measured]).

2. Google Cloud Platform (GCP)

export PROJECT_ID="your-gcp-project-id"
export ZONE="us-central1-a"
./docs/benchmarks/cloud/provision-gcp.sh

# Run the 5-node comparative benchmark suite and regenerate docs/benchmarks/*:
node docs/benchmarks/cloud/run-comparative-benchmarks.mjs --hosts "$HOSTS" --ssh-user "$SSH_USER" --regenerate-docs

# Tear down when finished:
./docs/benchmarks/cloud/provision-gcp.sh --teardown

3. Amazon Web Services (AWS)

export REGION="us-east-1"
export KEY_NAME="your-ec2-keypair-name"
./docs/benchmarks/cloud/provision-aws.sh

# Run the 5-node comparative benchmark suite and regenerate docs/benchmarks/*:
node docs/benchmarks/cloud/run-comparative-benchmarks.mjs --hosts "$HOSTS" --ssh-user ubuntu --ssh-key ~/.ssh/your-ec2-keypair.pem --regenerate-docs

# Tear down when finished:
./docs/benchmarks/cloud/provision-aws.sh --teardown
