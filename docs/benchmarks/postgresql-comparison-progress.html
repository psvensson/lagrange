Comparative evaluation of three control-flow models across Scenario B graph shapes:

  • PostgreSQL + Application Service: Business logic in external process; incurs 2.75 SQL round-trips/decision (520.0 dec/s single, 385.0 dec/s sync HA on local-only).

  • Lagrange WASI Service: Native partition state colocated with consensus (0 round-trips local), widening advantage under RPO=0 synchronous HA replication, multi-partition sequential/fan-out stages (380.0 / 410.0 dec/s), and live partition movement continuity.
