Three-Way Locality Control (Application Service vs PL/pgSQL Function vs Lagrange)

Comparative evaluation of three control-flow models across Scenario B graph shapes:

  • PostgreSQL + Application Service: Business logic in external process; issues SQL queries across client/database network boundaries (evaluating pg-single-primary and pg-patroni-sync-ha-rf3).
  • PostgreSQL + Server-Side PL/pgSQL Function: Logic in database procedure; collapses multi-statement round-trips while preserving ordinary-SQL Scenario A baseline (evaluating pg-plpgsql-single-primary and pg-plpgsql-sync-ha-rf3).
  • Lagrange WASI Service: Native partition state colocated with consensus; comparative performance claims await admitted GCP/lab measurements.
