2. **Own-property discipline.** Pass. The target decoder never accepts inherited `replica_count`/`replicaCount`: it walks the two accepted names and requires `Object.getOwnPropertyDescriptor(partitionRow, name)` plus an own `value` field on the descriptor (`src/bootstrap/replication-target-authority.js:53-70`).
3. **Accessor traps.** Pass. Getters on row fields are not invoked because `Object.getOwnPropertyDescriptor` reads the descriptor, the code skips descriptors without a data `value`, and it returns after the first present spelling (`src/bootstrap/replication-target-authority.js:53-70`). This avoids a re-read/TOCTOU path for the policy value.
4. **Prototype pollution.** Pass-with-caveats. Inherited pollution on `Object.prototype` cannot satisfy the decoder because only own data descriptors are accepted (`src/bootstrap/replication-target-authority.js:53-70`), and arrays are rejected before field decoding (`src/bootstrap/replication-target-authority.js:101-103`). Caveat: this Quest's witness does not set/restore hostile prototype pollution fixtures; the witness header says Quest A already proved the authority contract (`test/bootstrap/behaviour-changing-consumer-convergence.test.js:4-5`), while this Quest focuses on consumers.
5. **Boxed and exotic primitives.** Pass. A boxed `Number`, `String`, or `Boolean` in the row value fails `Number.isSafeInteger(value)` because it is an object, not a primitive number; Symbol-keyed values are ignored because only the two literal string column names are scanned (`src/bootstrap/replication-target-authority.js:49-70`).
6. **Mutable intrinsic methods.** Pass-with-caveats. The authority freezes the key object/number intrinsics it uses at module load (`Object.getOwnPropertyDescriptor`, `Object.hasOwn`, and `Number.isSafeInteger`) at `src/bootstrap/replication-target-authority.js:9-11`, and the decoder does not use `trim`, `replace`, `toLowerCase`, `RegExp.prototype.test`, array iteration helpers, `JSON.stringify`, or `Number.isFinite` on hostile policy values (`src/bootstrap/replication-target-authority.js:53-112`). Caveat: `Array.isArray` is called directly rather than captured (`src/bootstrap/replication-target-authority.js:101-103`); that is a theoretical mutable-intrinsic seam if globals are replaced after module load.
7. **Digest/serialization coercion.** Pass. The policy authority does not feed untrusted policy values to hashes, digests, canonical serialization, or `String(x)` before type-pinning; it reads the descriptor value and type-checks it as a safe integer (`src/bootstrap/replication-target-authority.js:53-70`). The consumer fallback-census receipt reads source files as strings, not live external payloads (`test/bootstrap/behaviour-changing-consumer-convergence.test.js:766-790`).

The authority's row input is expected to be an object record, not an array, and arrays are rejected as UNDECLARED (`src/bootstrap/replication-target-authority.js:101-103`). Service-row arrays used by recovery/rejoin/ledger are cache outputs rather than the target policy row and are not newly hardened by this candidate (`src/node/replica-recovery-service.js:212-218`, `src/bootstrap/shared/durable-rejoin-partition-restore-planner.js:275-283`, `src/rebalancer/operation-ledger-quorum-concentration.js:298-305`).
