existing repository recorder with a host-owned transport callback. An explicitly
selected existing node/replica is the witness route; the uncreated target is never
silently selected. The existing message envelope reaches the registered
MessageGroupServiceHandler, which receives the actual router delivery context as
its second argument. Payload receipt or context fields do not supply authority.

The recipient normalizes the exact learner query through the existing codec,
checks group/replica/node binding, resolves the hosted service and native port,

checks the original delivery, current handler registration, service object and
port identity. Its answer traverses the existing response/delivery owner. The
repository validates the original action and membership witness before the
existing exact-row CAS. Transport acknowledgement or COMPLETED is not an ADD,
CREATE, cancellation, debt-release or successor grant.

The implementation uses two private helper modules for existing owner methods;
there is no additional registry, durable store, retry coordinator or autonomous
reconciler. The workflow facade is implemented but no recurring workflow caller
is activated. Current CREATE remains parked.
