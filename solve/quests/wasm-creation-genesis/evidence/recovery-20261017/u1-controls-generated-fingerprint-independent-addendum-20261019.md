## Same-profile control contract

For each control, preserve the final positive candidate's complete executable
test and helper bytes, including assertions, expected values, messages,
fixtures, pause/release ordering, scheduling budgets, cleanup, selection and
runner configuration. Preserve all test membership, classifications,
thresholds and curated impact-contract registry bytes. Preserve all production
bytes except the one declared owning-file mutation. No new helper or alternate
test entry point may select behavior for the mutant.

Run the existing required producers and normal hooks. Canonical generated
source fingerprints and deterministic source inventories may change only as
the direct consequence of that declared source mutation. Record each such
file's positive and mutant hashes and complete diff separately from the
production patch. The inventory's observed source facts may reflect the
mutation; its policy inputs, limits and classification rules remain frozen.
Do not manually alter output, disable hooks, or retain deliberately stale
seals to force equality.

Record both actual full Git trees and actual Git `test` trees, even when the
latter differ because of the seal. Also retain a per-file digest manifest of
all executable test/helper and runner inputs and confirm that it is identical
between the positive and each control. Record the exact selected file list,
classifications and execution profile separately. A claim of unchanged
oracles refers to that manifest, not to falsely equal Git trees.

An unexpected change to test membership, classification, thresholds, curated
contracts, executable inputs or undeclared source makes the pair ineligible
under this approval. A generated label is not an exemption. Resolve and
explain the extra difference before execution or record the experiment as
outside the approved pair; do not silently absorb it. Fresh metadata does not
replace the first-result receipt or turn an import, setup, interface, timeout
or unrelated assertion failure into a meaningful mutation result.
