### Recovery boundaries and paired checks

- **Placement and dispatch.** Trace one operation and attempt from the durable grant, through the target worker, to activation and source observation. An actual target worker must exist for a repeated delivery to be suppressed. Refusal, an expired worker or a changed boot must permit redelivery. Measure completed copies and their service times alongside process, thread and event-loop pressure. Envoy also uses latency from completed requests for its adaptive limit. [Dispatch completion history](../../operation-dispatch-completion-owner-cutover/log.ndjson) · [Envoy adaptive concurrency](https://www.envoyproxy.io/docs/envoy/latest/configuration/http/http_filters/adaptive_concurrency_filter.html)
- **Retention and retirement.** Exercise both obligations in the same lifecycle. An uncertain acknowledgement keeps the grant. Once the authoritative terminal decision releases that exact fence, the previous group can retire, its descriptor can be removed, and a successor can register. With two grants, settling the first must preserve the second through restart. PostgreSQL replication slots likewise tie retained data to a consumer's progress. [Split/merge history](../../../epics/split-merge-transition-integrity.md) · [PostgreSQL replication slots](https://www.postgresql.org/docs/current/warm-standby.html#STREAMING-REPLICATION-SLOTS)
- **DDL and query cancellation.** A client can lose its connection after a schema job was accepted. A fresh client must be able to identify the same job, write its table, and read the row after reopen with surviving voters. An ordinary cancelled query has a different obligation. Its next submission must stop after a cooldown, while a committed result remains available. CockroachDB exposes accepted schema work by job ID. gRPC describes cooperation by the handler when cancelling work it starts downstream. [Schema job history](../../application-operating-envelope/log.ndjson) · [CockroachDB online schema changes](https://www.cockroachlabs.com/docs/stable/online-schema-changes) · [gRPC cancellation](https://grpc.io/docs/guides/cancellation/)

### Bounded retries and session recovery

The shared reconcile queue dates to `d29c7d8c8`. A bounded retry burst can finish while the index catalog still records an unfinished generation. The dedicated GSI exhaustion witness drives all 20 attempts, restores the dependency and exercises an ordinary inventory wake. The current generation and a second index both have to make progress. Kubernetes client-go also maintains retry counts per item and lets its controller explicitly clear that retry history. Lagrange uses the index generation and the durable schema result to decide whether another burst is warranted. [Kubernetes rate-limiting workqueue](https://github.com/kubernetes/client-go/blob/master/util/workqueue/rate_limiting_queue.go)

The standalone PG-wire rollback witness on the ce239691d production tree reproduced the failed-block cascade on one TCP session. The transaction's durable rollback decision preceded the first unsuccessful participant rollback. The following invocation sent BEGIN and received 25P02. PostgreSQL exposes a failed transaction block as a connection state distinct from idle and supports ROLLBACK on that same connection. The candidate witness requires durable participant settlement and a subsequent successful transaction after availability returns.
