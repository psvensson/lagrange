## Approved bounded change

1. Return the already constructed `controlPlaneSystemTableGateway` in the ControlPlaneSetup bundle. Seed and join initializeControlPlaneService retain that exact object before runtime setup. Initialize the field explicitly alongside their other control-plane references. The returned object must be the dispatch gateway; for the ordinary fresh-coordinator construction it must also be the coordinator gateway. An externally supplied coordinator can retain its existing gateway under current code: this patch must not claim to normalize every reuse branch or silently replace another owner's live dependency. No unrelated gateway factory/reuse redesign is approved here.
2. Pass the field to the existing PgWireStartupSafetyGate and add one named prerequisite requiring a callable readAuthoritativeRows. Missing/null or malformed ports produce its ordinary BLOCKED result and named blocking dependency before the guarded setup callback/registration. The gate remains an availability precheck, not serving or definition authority; a present gateway can still return the existing typed UNAVAILABLE during CREATE. Preserve startup-failure isolation and the existing owner order. Do not throw before the gate, add a fallback or relax the handler's authoritative read. Keep RuntimeServiceHandlerSetup tolerant for its separate invocation-only use, as requested.
3. Clear the seed and join field through their existing control-plane cleanup owners alongside the other retained references. Join's cleanup delegate should expose the canonical setter rather than an optional compatibility ladder. This is reference custody: do not add a gateway shutdown API or tear down a shared gateway from this consumer. Existing runtime/dispatch/transport quiescence still owns live ingress. Cleanup followed by a subsequent proper initialization must select the new returned object, not retain the previous one. No new timer, wait or enlarged budget is needed.
4. Extend the existing runtime-definition interaction to bind construction, guarded startup, cleanup and their live witness tests. Keep unrelated planning memoization, local-runtime grace, generic REMOVE and cleanup-token mechanisms out of this unit; no prior report label is implicit authorization to implement them.
