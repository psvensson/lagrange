# Theory Ledger Entry Template

Copy this block into `work/theory-ledger.md` under `## Entries`.

```markdown
## theory-YYYYMMDD-short-slug

- Status: active
- Scenario/gate: scenario-or-none / gate-or-none
- Owner/boundary: owner_name / boundary_name
- Hypothesis: one falsifiable theory or experiment result.
- Probe: `npm run command -- args`
- Artifact/result: `path/to/artifact-or-package.md` - short result.
- Representative movement: pending-before-probe|representative-green|reduced|migrated|same-frontier|classification-only|architecture-gap|needs-rerun|none
- Linked packages: `work/packages/active-or-done-package.md`
- Supersedes: none
- Superseded by: none
- Next implication: next package, rerun, architecture gate, or stop condition.
```
