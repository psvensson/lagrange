# Contributions

This project is open source (AGPL-3.0) but **does not accept code contributions**.
Pull requests are disabled on this repository, and patches sent by other means
will not be merged.

Two reasons:

1. **Copyright.** I intend to offer commercial licenses alongside the AGPL in the
   future. That requires sole ownership of the copyright, so I cannot merge
   third-party code — and soliciting free work I would later sell would be
   dishonest.
2. **Volume.** Unsolicited (increasingly AI-generated) pull requests take real
   time to review, and I'd rather spend that time on the project itself.

You are of course free to fork and modify the code under the AGPL-3.0 terms.
Bug reports and reproducible failure cases are welcome via the issue tracker.
