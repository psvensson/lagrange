## First Violated Invariant

A scenario run that PASSES must still record its measured publication-convergence evidence
(`publicationConvergence.missingPublishedCount` and the published active-node set) in the run
report. Convergence evidence must NOT be gated on the failure-bundle path. The statistical gate
classifies each run by the independent measured `missingPublishedCount` (deliberately, NOT by the
scenario's own `passed` flag — see [[rolling-restart-stat-gate.sh]] header), so a passing run that
emits no `publicationConvergence` is read as `missing=null` and downgraded to SLOW — masking a
genuine convergence and the very signal needed to validate any convergence fix.
