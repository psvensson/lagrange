### Drain-step-timing diagnosis 2026-06-18 (user: "diagnose drain-step timing first")
**SMOKING-GUN TIMING COLLISION:** the harness restart path is restartNode →
chaos.stopNode → dockerProvider.stopContainer → `container.stop({t: STOP_TIMEOUT_SECONDS})`
(docker-provider.js:521-527). `STOP_TIMEOUT_SECONDS = 10` (docker-provider.js:20) =
docker's SIGTERM→SIGKILL grace. The app's graceful-drain budget
`READINESS_DRAIN_DEADLINE_MS = 10000` (src/constants/entrypoint.js:39) is the SAME 10s.
**Zero slack:** the instant the app's drain deadline elapses, docker is already at its
SIGKILL point. The failing drains are buried in `Query timeout after 10000ms` (also 10s)
— so a drain that waits on an in-flight query consumes the entire window and loses the race.
This directly motivates fix-A: decouple the two — give the container stop-grace headroom
ABOVE the drain deadline (e.g. STOP_TIMEOUT 10s→20-25s, or drain deadline < stop grace) so a
clean drain reaches exit(0) before SIGKILL.

CAVEAT (honest): exact per-STEP attribution (which awaited step — query-executor drain /
ownerCleanup / bootstrapAPI.shutdown / adminRuntime shutdown — consumes the window) could NOT
be read cleanly from the playback logs: they are a MERGED MULTI-INCARNATION capture, so the
"Shutdown already in progress" / "Shutting down..." lines interleave across a node's several
restart cycles and timestamps are not monotonic in file order. Need a single-incarnation trace.

NEXT (low-risk, observe-only): add per-step timing logs to the shutdown handler
(entrypoint-runtime-shutdown-lifecycle.js:218-260) — wrap each await (submitDrainIntent,
publishNodeShutdownStatus, logs/owner/bootstrap/admin shutdown) with a start/elapsed log — then
one DEBUG-capture or N=3 run names the dominant step. THEN choose: A (decouple stop-grace vs
drain deadline — strongly indicated already), C (bound the slow step), and/or B (don't code a
within-deadline in-progress drain as exit-1). Do NOT edit the harness stop-grace until the step
trace confirms the drain actually COMPLETES when given headroom (else fix-A masks a hung step).
