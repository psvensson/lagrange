# Distributed Closure Ledger

## Purpose

This ledger tracks the remaining distributed-runtime closure work for the
membership lifecycle and placement hard cutover using the grammar defined in
`closure-grammar.md`.

Each record represents one violated invariant.

## Organization

This file is the **index**. Each closure record lives in its own file under
[`closure-ledger/`](closure-ledger/) (`closure-ledger/CL-###.md`), so a record's
full current state — header fields, evidence, gate verdicts, and worklog — is
self-contained in one place. To read a record, open its file directly (e.g.
`closure-ledger/CL-033.md`); the Status Summary below links each id. To add a
record, create `closure-ledger/CL-###.md` and add one linked row here. See
`closure-grammar.md` for the record grammar and per-record field definitions.
